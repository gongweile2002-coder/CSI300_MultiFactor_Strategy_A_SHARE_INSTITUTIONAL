# 交易规则与接口依据

规则核查日期：2026-09-11；Tushare日线与迅投接口文档于2026-09-12再次核对。本次 v9 更新为数据和操作一致性改进，不新增交易品种或交易时段。以下为官方来源和在本版中的使用方式。交易规则以现行中文原文、交易所后续公告和券商账户适用规则为准；软件自身可以采取更保守的限制。

## 交易所

[上海证券交易所交易规则（2026修订，官方英文参考译本）](https://english.sse.com.cn/start/sserules/stocks/trading/c/10825757/files/d263e3a87f37436ca2f8e5bcfc4ff001.pdf)。核查条款：2.4.2（时段）、3.1.4（交收前卖出限制）、3.1.8（程序化交易报告）、3.3.8—3.3.14（数量、价格步长和价格范围）、3.7（盘后方式）、6.7（科创板数量）。

本版限定连续竞价，普通主板按100股整手买入、清仓处理零股；科创板保守按至少200股的限价数量规则，并限制所有支持板块单笔不超过10万股。程序化交易规则涉及通过计算机自动生成或发送指令，人工点击提交不能被当作当然免报告的依据，具体应与券商确认。价格限制用证券当天资料，遇到无有效限制价格的证券不交易。本版不实现盘后方式；不能把它误解为交易所没有盘后交易制度。QMT采用保守2%价格范围，不扩展使用10个价格步长容差。

本次未取得可稳定打开的深交所2026中文完整规则页，未声称已对其全部条款逐条复核。深市委托使用券商实时证券资料和账户权限，默认主板；创业板默认关闭，启用前需向券商复核当前数量、价格和权限要求。

## 迅投 / MiniQMT

[xttrader 交易API](https://dict.thinktrader.net/nativeApi/xttrader.html)：持仓数量与可用数量为不同字段；限价委托返回券商委托号，不代表成交。代码以账户查询、委托查询和累计成交量为对账依据，使用固定价格委托，保持策略备注和本地委托ID映射。

[xtdata 行情API](https://dict.thinktrader.net/nativeApi/xtdata.html)：使用完整快照、证券资料中的涨跌停价和交易状态。代码识别连续竞价、临时/全天停牌状态；未知状态停止。接口字段和SDK版本仍应在券商终端核对。

## Tushare

[Tushare A股日线](https://tushare.pro/document/2?doc_id=27)：原始日线不复权，成交量与成交额有其接口单位。本版下载器统一转换为股和人民币元，保留原始价用于交易，复权价只用于研究。

[Tushare 交易日历](https://tushare.pro/document/2?doc_id=26)：读取明确的交易/休市日期，不自行把工作日等同于交易日。

[Tushare ST 股票列表](https://tushare.pro/document/2?doc_id=397)：支持按日期/日期范围取得历史ST列表，并有单次返回上限。本版按股票分年请求，失败不降级为已确认没有ST风险。

本版还调用供应商的指数权重、复权因子、估值、财务和行业接口。权限、完整性、月内成分精度和财报修订历史仍需实际账户验证；本包没有代用户取得授权数据。

## 费用口径

[SSE收费说明](https://english.sse.com.cn/start/taxes/)说明交易所相关费用，但它不是用户券商全部收费项目的交割单。配置中的佣金、最低收费、过户费与卖出税费均为可调整的估计值，不意味着已经核实用户实际费率，也不保证未来不变。上线时应按现行税费、券商协议及实收口径检查重复计费和最低收费。
