## 四个固定实验

| 名称 | 评分规则 | 目的 |
|---|---|---|
| `core` | 价值 30% + 质量 40% + 126 日动量 30% | 原核心评分的研究基线 |
| `skip_momentum` | 价值 30% + 质量 40% + 跳月动量 30% | 动量使用 `P(D−21)/P(D−126)−1`，排除最近一个月 |
| `quality_lowvol` | 价值 20% + 质量 50% + 低波动 30% | 低波动为最近 60 个交易日收益标准差的负值 |
| `buffered_core` | 与 `core` 相同 | 目标名单在前 K+10 名内优先保留，默认每次至多替换 3 个仍合格旧名字；至少持有 5 个市场交易日 |

跳月动量和低波动均在当日共同合格股票池内缩尾，并进行市值/行业中性化。价格特征不向前填补停牌/缺失行情。四组共用具备所有所需特征的股票池，因此基线不一定与生产系统当天的名单完全相同。

ST/成分资格失效、资料失效及行业约束优先于缓冲；这些退出单独计入 `ineligible_exits` / `constraint_exits`。替换数量仅限制主动排名替换，初始建仓、补齐资格失效的空位和风险约束处理不受这个数量限制。名字保留也不代表股数不变：仓位切换、价格漂移、现金和费用仍可能引发调仓。

默认最多 30 只，至少 15 只；单股 8%、单行业 30%、总仓位至多 80%（基准低于 MA120 时至多 40%）。约束下无法配置的资金保留为现金，不提高剩余股票预算。默认 `weekly` 为从比较区间起点开始每隔 5 个市场交易日生成一组目标；`daily` 每日，`monthly` 每个观察月份内最后可用信号日。最后一个比较交易日留给执行/估值。

## 直接运行

在项目目录运行。每次使用新的空输出目录，已存在结果不会被覆盖。

```bash
# 无需 Token：明确标为合成数据，检查流程
python strategy_lab.py --demo --output outputs/strategy_lab_demo

# 真实数据：先完成 v9.3 数据下载/更新和审计
python update_live_data.py --output data/live --lookback-years 3
python strategy_lab.py --data data/live --output outputs/strategy_lab_real_01

# 相同四组策略，日频比较，固定日期及缓冲参数
python strategy_lab.py --data data/live --frequency daily \
  --start 2025-01-02 --end 2026-09-30 \
  --rank-buffer 10 --max-replacements 3 --min-hold-sessions 5 \
  --output outputs/strategy_lab_daily_01
```

真实研究也可使用保存的完整历史数据包：校验清单 SHA256，再按清单 `as_of` 做数据语义审计，不要求历史包更新到今天。历史整体漏掉一个交易日、基准漏交易日、涨跌停边界非法、某个请求信号日完全缺少合格股票池时会停止；个股无法成交则由研究执行器保守拦截，并输出拦截数量。历史估值必须是信号日当天，财报须满足 `ann_date < signal_date` 且公告年龄不超过 200 天；成分快照年龄不超过 45 天。

## 从哪里看结果

打开输出目录中的文件：

| 文件 | 内容 |
|---|---|
| `comparison.csv` | 4 个策略 × 2 个费用场景 × 全样本/后段样本，共 16 行；净收益、回撤、换手、费用及拦截次数 |
| `daily_returns.csv` | 扣费日收益及严格日期对齐的基准收益 |
| `targets.csv` | 每组历史目标名单和权重，`source=research_only` |
| `selection_audit.csv` | 留存、新进、主动替换、资格失效和风险约束退出 |
| `factor_audit.csv` | 财报公告日、估值日期、跳月起止日期和各组分数 |
| `holdings.csv` / `trade_costs.csv` | 模拟执行持仓、成本和因限制未能成交的次数 |
| `research_manifest.json` | 完成标记、源数据摘要、参数、文件哈希及局限；写入失败不会产生完成标记 |

`base` 使用佣金 3 bps、最低佣金 5 元、滑点 2 bps、过户费 0.1 bps，并按历史日期计卖方印花税。风控配置中的佣金、最低佣金、过户费及 ADV 比例可覆盖默认值。`fees_x2` 加倍佣金、最低佣金、滑点和过户费，法定印花税不加倍。

`holdout` 是固定最后 30% 交易日的描述性比较，沿用此前持仓；没有训练模型、调参或根据结果自动选冠军。若看完后段结果再调参数，这一段也不再是未见样本，应使用新的时间窗口继续检验。

## 研究模拟与 Paper 的边界

本次沿用 `accounting_backtest_v8`：调整后的经济单位、现金约束、涨跌停拦截、最低佣金、历史印花税和流动性参与上限。目标使用 D 收盘已知资料，执行严格晚于 D；研究股数按执行开盘换算。它与 v9.3 的 D 收盘固定股数、公司行动入账和 SQLite 事务账本不同，不能直接等同于可交易的前向 Paper 结果。

研究撮合假设毛分配再投资，未模拟分红税/到账时间、配股选择、真实盘口、退市清算。`cost_nav_fraction_sum` 是每次成本/NAV 的累计诊断值，不是严格的扣费前后收益差。vendor 后来修订的财报、近似成分快照和 ST 历史降级也会限制历史 PIT 的真实性；这些来源说明保存在清单里。

所有研究结果保持 `performance_validated=false`、`real_broker_submission=false`。结果没有真实委托信号清单，不能送入 `live.py` 的下单链路，也不会写入 `paper/live`。结果目录已被 `.gitignore` 排除，不提交历史候选和持仓到公开仓库。
